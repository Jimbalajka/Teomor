## 2026-10-03 — старт агент-контекста

**Решение:** завести в `Jimbalajka/Teomor` папку `godot/` с тремя файлами памяти агента.

**Почему:** отдельный Godot-продукт в том же гите; HTML-корень не трогаем; агенту нужны раздельные роль / контекст / лог.

**Утверждено автором (анкета):**
- Роль: техлид с голосом, без решений; предлагать упрощения.
- Процесс: хочу → план/решение → OK → делаем.
- A3: предупреждать о раздуве; цель — небольшой хороший продукт, глубина > ширина.
- Коммс: коротко/по делу на простом, подробнее на сложном; тон жёсткий; uncertainty = вопросы + best guess.
- Процесс шага: план → OK; куски 0.5–1 день; закрытие только после OK; документы обязательны.
- Scope: история; vertical slice; RPG-минималка; линейка; бой нормальный; 3 концовки; 3 крупных выбора в начале и конце главы; без OW/крафта/skill tree/мобилок/мультиплеера.
- Тех: Godot 4 / GDScript + мало плагинов; просто и стабильно; на слайсе заглушки + начало гл.1 + стиль; GUI — пошаговые клики.
- Канон: сюжет не трогать; руты можно упростить под объём; советы по лору только по запросу; RU → EN в конце.
- Стопы: всё из списка scope/вода/лор/чужие системы; при уходе — стоп + откат.
- Память: 3 файла (`AGENT` / `CONTEXT` / `CHANGES`).
- H1: скорее FPS/1 лицо. H2: скорее Godot, всё через агента. H3: slice как выше.
