# Как открыть маршрут в Godot

1. Godot 4.3+ → **Import** → `Teomor/godot`.
2. **Play (F5)**.

## Управление
WASD / мышь / E. Esc — отпустить мышь.

## Маршрут
1. Чердак → лестница → Грибной район.
2. В конце улицы выбор:
   - **На склад / верфи**
   - **В Конгрегационную библиотеку**
3. Верфи: пирсы, корабли, склад с лестницей на 2 ярус, Тон Тон, взгляд на огромную Вастерсу.
4. Библиотека: улица → зал, Раф, 5 отдел.
