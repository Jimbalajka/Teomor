# Free 3D Modular Prototyping (CC0)

Сырой пак в ~2 м модулях. Для Теомора прогнан через `bake_mesh_meters.gd`:

- `Pieces_*.glb` — **1 м** сетка (root scale 0.5 в `.import`)
- `Character_Character.glb` — scale 0.85; при инстансе **rotation_degrees.x = -90**

В редакторе не трогай Root Scale — значения уже в `.import`.
