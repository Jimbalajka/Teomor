# CONTEXT — Теомор Godot

Живой снимок проекта. Сюжет пишет автор; здесь — рамки и техника.

## Что это
- 3D-игра по миру Теомор на **Godot 4** (скорее да; почти всё ведётся через агента).
- Этот репозиторий (`Jimbalajka/Teomor`) — старый HTML/док-канон.
- Godot-ветка живёт **в папке `godot/`**, не смешивать с корнем HTML.

## Приоритет v1
1. История (автор пишет текст).
2. Стиль/атмосфера на слайсе.
3. Чтобы стабильно игралось.

## Scope
**Делаем**
- Линейная история, «кишкообразные» локации (коридор/хаб с ответвлениями, не open world).
- Нормальный бой (без лишней глубины систем).
- 3 концовки.
- По **3 крупных выбора** в начале и в конце главы.
- Руты: минимум работы на каждый; где дорого — упрощаем структуру, сюжетную суть не ломаем.

**Не делаем без отдельного OK**
- open world
- крафт
- skill tree
- мобилки
- мультиплеер
- пачка мелких концовок сверх трёх

## Камера / POV
Скорее **от 1 лица** (проще; окончательно не зафиксировано — сменить можно планом + OK).

## Стек (предложение, принято по умолчанию пока автор новичок)
- Godot 4
- **только GDScript**
- минимум плагинов
- архитектура: аккуратно, но тупо и прямо; цель — мало вылетов, без overengineering

## Контент / ассеты (E3)
На vertical slice:
1. заглушки + сбор **начала 1 главы**
2. проработка стиля (не весь контент — якорь стиля)
3. дальше по игре — чисто заглушки
4. полировка контента — в самом конце

## Статус сцены (2026-10-03)
Старт: `scenes/attic.tscn` (без меню).
Маршрут: чердак → лестница E → длинный узкий тупик (бочки) → T-стык на перпендикулярную улицу шире; 2 НПС + труп; выбор: верфи/склад **или** библиотека; Вастерса-мегаструктура вдали; мягкие барьеры на открытых зонах.
Лестница у стены. Возврат E → чердак.
Визуал: только примитивы-заглушки.

## Первый milestone (H3)
**Vertical slice:** заглушки + начало главы 1 + якорь стиля.
Не style-spike отдельно и не серый greybox без истории.

## Канон относительно HTML-Teomor
- Сюжет/лор автора — источник; агент не переписывает.
- Руты можно слегка поджать под объём работ (после OK).
- Системы из другого Теомора (древо/HTML/Teomor-sis) **не тащить** автоматически.
