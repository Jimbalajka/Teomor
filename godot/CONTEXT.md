# CONTEXT — Теомор Godot

Живой снимок проекта. Сюжет пишет автор; здесь — рамки и техника.

## Что это
- 3D-игра по миру Теомор на **Godot 4** (скорее да; почти всё ведётся через агента).
- Этот репозиторий (`Jimbalajka/Teomor`) — старый HTML/док-канон.
- Godot-ветка живёт **в папке `godot/`**, не смешивать с корнем HTML.

## Приоритет v1
1. История (автор пишет текст).
2. Стиль/атмосфера на слайсе.
3. Чтобы стабильно игралось.

## Scope
**Делаем**
- Линейная история, «кишкообразные» локации (коридор/хаб с ответвлениями, не open world).
- Нормальный бой (без лишней глубины систем).
- 3 концовки.
- По **3 крупных выбора** в начале и в конце главы.
- Руты: минимум работы на каждый; где дорого — упрощаем структуру, сюжетную суть не ломаем.

**Не делаем без отдельного OK**
- open world
- крафт
- skill tree
- мобилки
- мультиплеер
- пачка мелких концовок сверх трёх

## Камера / POV
Скорее **от 1 лица** (проще; окончательно не зафиксировано — сменить можно планом + OK).

## Стек (предложение, принято по умолчанию пока автор новичок)
- Godot 4
- **только GDScript**
- минимум плагинов
- архитектура: аккуратно, но тупо и прямо; цель — мало вылетов, без overengineering

## Контент / ассеты (E3)
На vertical slice:
1. заглушки + сбор **начала 1 главы**
2. проработка стиля (не весь контент — якорь стиля)
3. дальше по игре — чисто заглушки
4. полировка контента — в самом конце

## Статус сцены (2026-10-03 вечер)
Старт: `scenes/attic.tscn` (без меню) + ввод имени.
Маршрут: чердак → Грибной (T-стык, НПС/труп, POI) → склад **или** Конгрегационная → (пожар→улица) и/или лавка странностей → пропуск → заглушка Центральной.
Газета/гулять вырезаны. Бой и зарплатные исходы — позже.

**Визуал v1.2 (`60d065f`):** baked albedo + sick-vision filter; чердак со скатом/балками; переулок светлее; гриб-текстуры только на мешах. Автор: текущие «текстурки» ещё не ок (плоско/наклейки) — завтра продолжаем по скрин-фидбеку; геометрия важнее новых PNG. ComfyUI локально нет (MX110 / нет GPU на агенте).

Живой handoff: [`docs/SESSION.md`](docs/SESSION.md).

## Первый milestone (H3)
**Vertical slice:** заглушки + начало главы 1 + якорь стиля.
Не style-spike отдельно и не серый greybox без истории.

## Канон относительно HTML-Teomor
- Сюжет/лор автора — источник; агент не переписывает.
- Руты можно слегка поджать под объём работ (после OK).
- Системы из другого Теомора (древо/HTML/Teomor-sis) **не тащить** автоматически.

## Язык
- В игре и рабочих текстах сейчас: **только русский**.
- Английский перевод — в самом конце проекта.

## Документы
Обязательны короткие, но нормальные GDD/чеклисты (не «только код в голове»).
Старт: эти 3 файла; GDD-скелет — отдельным шагом после OK.

## Дизайн локаций
Каждая локация: маршрут сюжета + 1–3 необязательных POI (вид/объект/текст), чтобы было куда «залипнуть». Референс ощущения: Dread Delusion.

## Решения по slice (2026-10-03, ответы автора)
- Работы Дня 1: **склад** и **библиотека**. Газету как работу убираем.
- «Пойти гулять» пока выкидываем (раздувает).
- **Лавка странностей обязательна** (3D-пространство автор пришлёт позже).
- Исходы зарплаты/увольнения — механика, **позже**.
- Имя героя: **вводит игрок**.
- Конгрегационная библиотека (Раф) ≠ Центральная библиотека (гораздо больше).
- Бой в Дне 1 будет; боевая система нужна — отдельным блоком, не смешивать со всеми локациями сразу.
- POI: на локациях брать из описаний/HTML (гамак, крысы, трюм/кран и т.д.); читаемые карточки в библиотеке — позже как механика.
- POI = необязательная точка интереса (объект/вид/короткий текст), не обязательный квест.
