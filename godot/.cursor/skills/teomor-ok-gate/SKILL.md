# teomor-ok-gate

## Процесс
1. Автор хочет X
2. План / варианты (коротко)
3. **OK автора**
4. Работа
5. Отчёт (что смотреть / коммит)
6. Шаг закрыт только после OK

## Стоп без отдельного OK
- Teomor-sis / skill tree / HTML-древо
- бой, зарплата, чтение полок как механика
- open world / крафт / мультиплеер / мобилки
- полировка склада/библиотек «под финал»
- сам пишу/меняю сюжет

## Исключения (можно без полного grill)
- Опечатка / сломанный путь / явный однострочный фикс
- Документация handoff по просьбе «запомни / SESSION»

## Роль
Техлид с правом голоса, **без права решений**. Scope creep — предупредить и ждать.
