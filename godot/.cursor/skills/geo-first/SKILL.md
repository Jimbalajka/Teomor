# geo-first

## Триггеры
«плоско», «дёшево», «коробка», «нет рельефа», сравнение с DD / Lunacid / SH.

## Порядок удара
1. Силуэт — проёмы, карнизы, хлам, ниши, разломы
2. Свет — ключ/fill/тени, контраст, короткая дистанция
3. Масштаб UV — крупное пятно материала (кирпич не «плитка»)
4. Текстуры / bake — только если форма уже читается

## Запрет по умолчанию
Не предлагать «ещё пачку PNG / нейросеть» как первый ответ на «плоско».
