# session-handoff

## Когда
- Конец сессии / «завтра» / смена фокуса
- После крупного пуша стиля
- Автор просит «запомни где остановились»

## Минимум в `docs/SESSION.md`
- Дата + коммит/ветка
- Где мы (маршрут + визуальный статус)
- Что смотреть после pull
- Следующий шаг (1–3 пункта)
- Не трогать без OK

Параллельно короткая строка в `CHANGES.md`, если было решение.
