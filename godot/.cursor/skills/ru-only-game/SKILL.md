# ru-only-game

## Правило
- В игре: только русский (промпты E, реплики, UI ввода имени)
- Рабочие доки проекта (`godot/*.md`, `docs/*`): русский
- Английский перевод — в самом конце проекта, отдельным OK

## Исключения
- Идентификаторы кода / пути файлов / имена текстур
- Цитаты внешних API / лицензий
