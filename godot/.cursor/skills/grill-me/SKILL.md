# grill-me — уточнение до работы

## Когда (сам, без слэша)
- Задача похожа на >15 минут
- Автор сказал «сделай / поправь / давай» без чётких границ
- Неясно: сцена, критерий «ок», пушить или нет

## Что спросить (коротко)
1. **Цель** — что должно стать лучше
2. **Сцена / зона** — чердак / переулок / лавка / …
3. **Критерий ок** — как поймём, что хватит
4. **Не трогать** — стоп-лист на этот кусок
5. **Пуш** — только локально или «смотри на гите»

## Как отвечать
- 1–3 варианта решения + рекомендация
- **Ждать выбор / OK** — не кодить до ответа (кроме тривиального бага <5 мин)
- Без воды; вопросы списком

## Не путать
grill-me ≠ отказ работать. Это сужение задачи перед кодом.
