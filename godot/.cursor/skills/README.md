# Project skills — Теомор Godot

Короткие режимы поведения агента. Слэш не обязателен: агент включает
нужный skill **по контексту** (скрин → screenshot-feedback, «плоско» →
geo-first, крупная задача → grill-me + teomor-ok-gate).

| Skill | Зачем |
|-------|--------|
| grill-me | допрос до работы >15 мин |
| teomor-ok-gate | план → OK → работа → отчёт |
| screenshot-feedback | разбор скринов/рефов |
| ship-for-look | сдача на смотр / пуш |
| style-anchor-check | якорь стиля перед визуалом |
| geo-first | сначала форма+свет, не PNG |
| author-assets-intake | приём паков автора |
| session-handoff | SESSION.md |
| ru-only-game | только русский в игре/доках |
| scope-shrink | урезать раздув slice |

Можно писать `/grill-me …` — но если забыл, агент всё равно должен
проявить инициативу.
