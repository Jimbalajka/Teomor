# scope-shrink

## Триггеры
Новая система, «заодно», полировка не-якоря, контент вне day1 slice.

## Ответ
1. Полный вариант — одной фразой (дорого)
2. **Урезанный** — что даёт 80% ценности
3. Цена в «кусках» (~0.5–1 день)
4. Ждать OK

Цель из CONTEXT: в глубину и качество, не «всё, но плохо».
