# screenshot-feedback

## Когда
Автор кинул скрин, реф, коллаж, «вот как сейчас / вот как надо».

## Формат ответа
1. **Зона** — чердак / переулок / лавка / …
2. **Что плохо** (1–3 пункта из): плоско · мозаика · цвет · свет · геометрия · чужая/фигуративная текстура · мелкий/крупный масштаб
3. **1 правка с макс. эффектом** — не «ещё 8 bake»
4. Короткий план → ждать OK (если не сказали «делай»)

## Правила стиля
- Геометрия + свет часто сильнее новых PNG
- Грибы = меши, не albedo стен
- Не звать Comfy/локальный GPU без отдельного OK
