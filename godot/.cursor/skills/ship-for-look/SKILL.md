# ship-for-look

## Порядок
1. Правка в коде / текстурах
2. `godot4 --path . --headless -s res://scripts/build_scenes.gd` (если трогали генератор)
3. Короткая запись в CHANGES.md (если решение)
4. **Push только если** автор сказал смотреть / «на гит» / «пушь»
5. В ответе: коммит · сцена (обычно attic→alley) · 2–3 чекпоинта «на что глянуть»

## Если пуш нельзя
Сказать: готово локально, жду «смотри» для push.

## Не смешивать
Не пихать в один пуш бой + стиль + сюжет. Один визуальный/технический кусок.
