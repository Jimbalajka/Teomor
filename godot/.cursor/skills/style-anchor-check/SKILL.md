# style-anchor-check

## Перед правкой визуала
Сверить `docs/STYLE_ANCHOR.md` + `docs/TEXTURES.md`:

| Правило | Суть |
|---------|------|
| Доминанта | один главный цвет зоны; два других — поддержка |
| Базы | пергамент / пурпур / чернила — никогда чистые |
| Грибы | только меши (+ flesh/cap maps); не на стены автоматом |
| Приоритет | форма и свет > новый bake PNG |
| GPU | не Comfy на MX110 / агенте без OK |

## Author packs
Рабочие карты: `assets/textures/author/`. Раскладка автора важнее «красивого» CC0.
