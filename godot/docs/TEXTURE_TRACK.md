# Трек-лист / чеклист текстур — Теомор

**Зачем:** разные модели = разные слоты дерева/камня/ткани. Не одну «деревяшку на всё».
**Формат слота:** albedo 512 (или 1024) seamless + желательно normal `_n` + rough `_r`.
**Куда класть:** `assets/textures/author/` (рабочие) или кинь автору-папку → агент вшьёт.
**Стиль:** грязный пергамент / пурпур / чернила; Nearest; без чистого PBR-глянца. См. `STYLE_ANCHOR.md`.

Статусы: ✅ есть · 🟡 есть, но слабый/временный · ❌ нет · 🔁 заменить

---

## 1. Дерево — три обязательных слота (не смешивать)

| # | Слот | Куда сажать | Что должно читаться | Статус сейчас | Файл-цель |
|---|------|-------------|---------------------|---------------|-----------|
| W1 | **wood_floor** | полы, половицы, настилы, ступени пола | широкие доски, щели, потёртость ног | 🟡 `wood_hand` / `wood_weathered` временно на всё | `wood_floor_512.png` (+n/r) |
| W2 | **wood_wall** | обшивка стен, панели, перегородки, рамы окон/дверей | более узкая вертикальная/горизонтальная обшивка, чуть светлее пола | ❌ | `wood_wall_512.png` (+n/r) |
| W3 | **wood_prop** | столы, стулья, кровати, полки, ящики, рукояти | мелкозернистее, темнее, «мебельное» | 🟡 тот же `wood_hand` | `wood_prop_512.png` (+n/r) |
| W4 | **wood_beam** *(опц.)* | балки чердака, стропила, толстые брусы | почти чёрно-коричневое, грубый тёс, ink в порах | 🟡 нет отдельного; балки едят W1/W3 | `wood_beam_512.png` (+n/r) |

**Правило:** пол ≠ мебель ≠ стены. Если на столе виден «напольный» масштаб досок — слот неправильный.

## 4. Привязка к моделям (что красить чем)

| Модель / зона в `asset_room` | Albedo-слоты |
|------------------------------|--------------|
| Пол зала | **W1** wood_floor |
| Перегородки / рейки рам | **S1** plaster + **W2** wood_wall на рейках |

| Матрас / подушка | **C1** cloth_worn |

| Окна | **W2** рама + **G1** стекло |
| Бочки / ящики | **W3** + **M1** обручи |
| Грибы / blob-наросты | **O1** / **O2** |
| Деревья / кусты / горшки | **O3** + **O4** + **W3** горшок |

| Цоколь улицы | **S5** |
