# Якорь стиля — Теомор Godot

**Статус:** v1.6 (2026-10-04). Author packs + world UV (крупный brick) + DD-like key/fill + geo ledges/пилоны. Палитра та же.
Остальные локации подтягивать позже.

## Правило кадра (из Блича TYBW + рефы автора)
В каждом кадре/зоне — **один доминирующий цвет**. Остальные два — поддержка, не равны.
Чёрное = мазки пера / провалы / грязь, не «третий главный».

| Зона | Доминанта | Поддержка |
|------|-----------|-----------|
| Чердак | грязный пергаментно-жёлтый | пурпур в углу, чёрные швы |
| Грибной переулок | грязный пурпур (всегриб / больное зрение) | тёплый пергамент в fill2, чёрные швы |

## Три базы (никогда чистые)
1. **Пергамент** — пыль, дерево, стены чердака  
2. **Пурпур** — форма Конгрегации / всегриб / акцент болезни (`цвет/`, `Эмб1`, костюм)  
3. **Чернила** — контур, швы, пятна (`стиль 1.1` полутон/штрих)

## Форма
Ломаем примитивы: споры у шляпок, наросты-blob, крупные отложения. Рефы: `Грибы/`, `цвет/`.

## Свет / зрение
Тускло, короткая дистанция, сильнее туман. Контраст выше насыщенности (adjustment sat↓ / contrast↑). Не яркий PBR-инди.

## Техника якоря
- Albedo: `assets/textures/style/tex_*_512.png` (рефы автора + ambientCG CC0), fallback — noise
- Bake **сохраняет структуру** материала (не сплющивает в 2 цвета); проверка: `scripts/tools/check_textures.py`
- Triplanar UV с достаточным tiling (доски/камень читаются); filter linear+mips; без чистого PBR-блеска
- Emission только на пурпурных шляпках/наростах (слабо)
- Сборка: `scripts/build_scenes.gd`; fetch/bake: см. [`TOOLS.md`](TOOLS.md)
- Источники/лицензии: [`TEXTURES.md`](TEXTURES.md)

## Рефы в репо
- `цвет/` — пурпур костюма + Эмб1  
- `Грибы/` — форма  
- `стиль 1.1/`, `Стиль ост/` — ч/б грязь, зерно  
- `Стиль мои рисунки*` — авторский тон  

## AI-генерация
Готовые промпты и чеклист первой пачки: [`AI_ASSETS.md`](AI_ASSETS.md).

## Не делать на якоре
Полировку склада/библиотек, полный postFX-стек, чистые неоновые цвета, равное RGB-смешение трёх баз в одном кадре.
 v1.4 (2026-10-04). Палитра + **depth bake** (AO/bevel в albedo) + normal/rough из ambientCG; UV jitter против мозаики; sick-vision; гриб-maps только на мешах грибов.  
Остальные локации подтягивать позже.
