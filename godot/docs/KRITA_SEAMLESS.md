# Бесшовные текстуры в Krita — Теомор

Для якоря стиля: грязный пергамент / пурпур / чернила. Не фото-PBR.

**Размер слота:** 512×512 (потом можно 1024).  
**Куда класть готовое:** `godot/assets/textures/author/` или папка `Текстурки/` → агент вшьёт.

---

## 0. Один раз настроить Krita

1. Скачать Krita (официальный сайт) → установить.
2. **Настройки → Настроить Krita → Общие → Курсор** — по вкусу.
3. Палитра Теомор (создай набор цветов):

| Имя | RGB |
|-----|-----|
| Пергамент | `158, 128, 71` |
| Пергамент тёмный | `92, 71, 41` |
| Пурпур | `107, 41, 97` |
| Пурпур glow | `140, 46, 122` |
| Чернила | `13, 10, 13` |
| Дерево | `102, 71, 41` |

Добавить: палитра снизу → **+** → вбить RGB.

---

## 1. Новый файл под тайл

1. **Файл → Создать**
2. Ширина/высота: **512 × 512**
3. Цветовая модель: **RGB / 8 bit**
4. Фон: залить пергаментом или тёмным (зависит от слота)

---

## 2. Включить рисование «по кругу» (seamless)

Это главное.

1. Меню **Вид → Режим продолжения изображения (Wrap Around Mode)**  
   Или кнопка / хоткей (в русской Krita часто: **W** — проверь в «Настройки → Настроить Krita → Сочетания» → ищи Wrap).
2. Холст как бы зацикливается: ушёл за край — рисунок появляется с другой стороны.
3. Рисуй **только в этом режиме**, пока не закончишь базовый паттерн.

Если Wrap не находится:  
**Настройки → Настроить панели → покажи «Режим продолжения»** / ищи `wrap around` в поиске действий.

---

## 3. Как рисовать (чтобы было «как DD», не фото)

### Кисти
- Базовая круглая мягкая + жёсткая (Pixel / Basic)
- Текстурная кисть с зерном (Dirt, Chalk, Dry brush) — если есть в пакете
- Не используй фото-штампы кирпича 8K

### Порядок
1. **Крупные пятна** доминирующего цвета (70% кадра — один цвет зоны).
2. **Средние мазки** грязи / трещин / швов чернилами.
3. **Мелкое зерно** — полупрозрачным слоем, opacity 10–25%.
4. Чуть пурпура в щелях (для переулка) или пергамента в пыли (чердак).

### Правило кадра Теомор
- Один доминирующий цвет на текстуру.
- Чёрное = штрихи/дыры, не «третий главный».
- Без неона, без чистого белого, без глянца.

---

## 4. Проверка шва (обязательно)

Даже с Wrap проверь:

1. Выключи Wrap.
2. **Фильтр → Сдвиг / Offset** (Filter → Offset)  
   - X = 256, Y = 256 для 512px  
   - Wrap around / вокруг краёв = включено
3. Посмотри центр: если виден крест/шов — замажь клоном или кистью.
4. Offset обратно или снова 256/256 — шов должен исчезнуть.
5. Можно **Изображение → Узор → сместить** аналогично.

Альтернатива: скопируй тайл в новый файл 1024×1024 и раставь 2×2 — швы между плитками не должны читаться.

## 6. Нормаль / roughnessсть (позже, не обязательно)

Для v1 хватит **albedo (цвет)**.

Если захочешь объём:
1. Дублируй слой albedo → обесцветь.
2. Чуть усиль контраст = высота.
3. Плагин / внешний **Materialize** / **Awesome Bump** → Normal, Rough.
4. Имена: `имя_n_512.png`, `имя_r_512.png` рядом с albedo.

Пока можно не трогать — в игре уже есть свет/гео.

---

## 7. Экспорт

1. **Файл → Экспортировать**
2. PNG, без альфы (кроме оверлея грязи)
3. Имя как в таблице, размер 512×512
4. Клади в `Текстурки/` или шли агенту / в `godot/assets/textures/author/`

В Godot после импорта: на текстуре **Repeat** = Enabled (агент или ты в Import).

---

## 8. Мини-ритуал на 25 минут

1. New 512, палитра пергамент/пурпур/ink  
2. Wrap Around ON  
3. Крупные пятна → трещины ink → зерно  
4. Offset 256/256 → замазать шов  
5. Export PNG  
6. В Godot на куб/стену — смотри с 2 метров камеры  

Если «мелко как плитка» — в игре уменьши UV scale (или скажи агенту).  
Если «плоско» — сильнее контраст пятен + свет в сцене, не 4K деталь.
