# Локации (greybox / канон автора)

## Сцены
- `attic.tscn` — чердак
- `alley.tscn` — Грибной район; в конце выбор: склад **или** библиотека
- `warehouse.tscn` — верфи/пирсы/склад на суше у озера; Вастерса далеко (мегаструктура)
- `library_street.tscn` — улица/площадь к библиотеке (1 ярус)
- `library.tscn` — Конгрегационная библиотека, Раф, 5 отдел

## Вастерса
Мегаструктура на острове/озере, сотни «этажей» по ощущению. По мосткам-каналам — грузовые двумя полосами (в город / из города). Мостки уходят к башням в тумане.

## Верфи
Не только склад: пирсы, корабли, портовый хлам, кран-заглушка. Проходы наружу закрыты ящиками (мягкий лимит). Склад двухъярусный **с лестницей**.

## Библиотека
Путь из Грибного → улица/площадь → библиотека. Раф Лат Телий завтракает; 5 отдел — бюрократия. Ветки диалогов позже.
