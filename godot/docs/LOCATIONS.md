# Локации (greybox / канон автора)

## Сцены
- `attic.tscn` — чердак; ввод имени; POI
- `alley.tscn` — Грибной район; выбор: склад **или** библиотека; вход в лавку; POI
- `warehouse.tscn` — верфи/пирсы/склад на суше у озера; Вастерса далеко (мегаструктура); POI
- `library.tscn` — Конгрегационная библиотека, Раф, 5 отдел; пожар → улица; POI
- `library_street.tscn` — улица после пожара (лавки/таверна/толпа); вход в лавку
- `shop.tscn` — лавка странностей (3 выбора → пропуск-заглушка)
- `central_library.tscn` — Центральная библиотека (заглушка; ≠ Конгрегационная)

## Вастерса
Мегаструктура на острове/озере, сотни «этажей» по ощущению. По мосткам-каналам — грузовые двумя полосами (в город / из города). Мостки уходят к башням в тумане.

## Верфи
Не только склад: пирсы, корабли, портовый хлам, кран-заглушка. Проходы наружу закрыты ящиками (мягкий лимит). Склад двухъярусный **с лестницей**.

## Библиотека
Из закоулков — сразу внутрь Конгрегационной. Раф Лат Телий завтракает; 5 отдел — бюрократия. После пожара — просторная улица. Центральная библиотека — отдельная, больше; доступ через лавку/пропуск.
